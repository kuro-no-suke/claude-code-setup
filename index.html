1
ターミナルを開く

ターミナルは「コマンドを入力して操作する画面」です。怖くないです！

方法①（おすすめ）：⌘ + Space → 「ターミナル」と入力 → Enter
方法②：Finder → アプリケーション → ユーティリティ → ターミナル.app

黒または白い画面が開いたら成功です！

⚠️ Windows は Claude Code の公式サポート外です。できれば Mac を推奨します。

PowerShell を管理者として起動します：

スタートボタンを右クリック → 「Windows PowerShell（管理者）」または「ターミナル（管理者）」をクリック

2
Claude Code をインストール
✅ Node.js は不要！ 公式インストーラーが1コマンドで全部やってくれます。

ターミナルに以下をコピペして Enter を押すだけです！

curl -fsSL https://claude.ai/install.sh | bash

文字がたくさん流れますが正常です。止まったら完了です。

💡 Homebrew を使っている方はこちらが簡単です。
brew install --cask claude-code
❓ エラーが出た場合
インターネット接続を確認してから、もう一度コマンドを実行してください。
それでも解決しない場合は Homebrew 方式（上のタブ）をお試しください。
✅ Node.js は不要！ 1コマンドで完了します。

PowerShell に以下をコピペして Enter を押します：

irm https://claude.ai/install.ps1 | iex

文字がたくさん流れますが正常です。止まったら完了です。

winget install Anthropic.ClaudeCode
❓ エラーが出た場合
PowerShell を「管理者として実行」しているか確認してください（Step 1 を参照）。
3
Claude Code を起動する

ターミナルに以下を入力して Enter！

claude

起動すると利用規約の確認画面が出ます。そのまま Enter を押して進んでください。

💡 選択肢が出たら いちばん上（1番）が最初から選ばれた状態になっているので、そのまま Enter でOKです！
❓ command not found: claude と出た
ターミナルを一度完全に閉じて、開き直してからもう一度 claude を入力してください。
それでも出る場合は、Step 2 のインストールが正常に完了しているか確認してください。

PowerShell に以下を入力して Enter！

claude

起動すると確認画面が出ます。そのまま Enter を押して進んでください。

💡 選択肢が出たら いちばん上（1番）を選んで Enter でOK！
❓ command not found と出た
PowerShell を閉じて開き直してから再試行してください。
4
Claude アカウントでログイン
⚠️ ログインには Claude Pro 以上のプラン（月 $20〜）が必要です。
💡 課金後のコツ：Claude.ai でプランを契約した後は、一度ターミナルを閉じて開き直してから claude を起動すると、スムーズに承認画面へ進めます！

ログイン方法の選択画面が出たら：

👉 「Claude.ai subscription」を選んで Enter

🌐 自動でブラウザが開きます！
Claude.ai でアカウントにログインし、「認証する」をクリックするだけ。
ブラウザを閉じてターミナルに戻ると、接続が完了します。
💡 APIキーは不要！アカウントログインだけで OK。
❓ ブラウザが自動で開かない場合
ターミナルに URL が表示される場合は、それをコピーしてブラウザのアドレスバーに貼り付けてアクセスしてください。
❓ ログインできない・プランが必要と出た
Claude Pro 以上のプラン（月 $20〜）が必要です。
claude.ai でプランを確認・アップグレードしてください。
⚠️ ログインには Claude Pro 以上のプラン（月 $20〜）が必要です。
💡 課金後のコツ：Claude.ai でプランを契約した後は、一度 PowerShell を閉じて開き直してから claude を起動すると、スムーズに承認画面へ進めます！

ログイン方法の選択画面が出たら：

👉 「Claude.ai subscription」を選んで Enter

🌐 自動でブラウザが開きます！
Claude.ai でログインし、「認証する」をクリック。
ブラウザを閉じて PowerShell に戻ると接続が完了します。
💡 APIキーは不要！アカウントログインだけで OK。
❓ ブラウザが開かない場合
ターミナルに表示された URL をコピーしてブラウザに貼り付けてください。
