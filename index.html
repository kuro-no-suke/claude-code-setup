Claude Code セットアップガイド

4ステップ、コピペするだけで完了！

↑ セットアップ後こんな感じで使えます

0 / 4 ステップ完了 0%
1
ターミナルを開く

⌘ + Space を押して「ターミナル」と入力 → Enter

こんな画面が開いたら OK です！
※ 黒い画面の場合も白い画面の場合もあります。どちらでも問題ありません。

⚠️ Windows は公式サポート外です。Mac を推奨します。

スタートボタンを右クリック → 「ターミナル（管理者）」をクリック

2
Claude Code をインストール

以下をターミナルにコピペして Enter！

curl -fsSL https://claude.ai/install.sh | bash

こんな画面が流れます。止まったら完了です。

以下を PowerShell にコピペして Enter！

irm https://claude.ai/install.ps1 | iex

文字が流れて止まったら完了です。

3
Claude Code を起動する

ターミナルに入力して Enter！

claude

こんな画面が出ます。そのまま Enter で進んでください。

💡 「command not found」と出たら、ターミナルを一度閉じて開き直してください。

PowerShell に入力して Enter！

claude

こんな画面が出ます。そのまま Enter で進んでください。

4
ログインする
⚠️ Claude Pro 以上のプラン（月 $20〜）が必要です。
⚠️ 課金時の注意！
プランを選ぶ画面では、最初から「年間プラン」が選択された状態になっています。
まずは「月払い」に切り替えてから購入するのがおすすめです。使い続けると判断してから年間プランに変更しましょう。

こんな選択画面が出たら、いちばん上を選んで Enter

自動でブラウザが開くので、Claude.ai にログインして「認証する」をクリック。

💡 課金後はターミナルを一度閉じて開き直してから起動すると、スムーズに認証画面へ進めます。
⚠️ Claude Pro 以上のプラン（月 $20〜）が必要です。

選択画面が出たら、いちばん上を選んで Enter

自動でブラウザが開くので、Claude.ai にログインして「認証する」をクリック。

💡 課金後はターミナルを一度閉じて開き直してから起動するとスムーズです。
