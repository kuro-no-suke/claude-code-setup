# TOB予兆ウォッチ

TOB・MBO・親子上場の解消・地銀の再編の「予兆」を、公表情報から毎日機械的に拾うツール。

## ファイル
| ファイル | 内容 |
|---|---|
| `tdnet_watch.py` | TDnet の適時開示を取得し、サインを分類してレポートを作る |
| `watchlist.tsv` | 監視する銘柄（下記） |
| `edinet_queue.txt` | 親子関係をまだ確認していない銘柄の EDINET コード |
| `signals.csv` | 拾ったサインの累積ログ |
| `reports/YYYY-MM-DD.md` | 日次レポート |
| `RUNBOOK.md` | 毎日の自動実行の手順 |

## ウォッチリストの区分（`group`）
- `parent`: 親会社（議決権40%以上、または親会社・連結子会社と記載）がある
- `affiliate`: 議決権20%以上の大株主の法人がある
- `bank`: PBR1倍割れ、時価総額1,500億円以下の地銀
- `screen`: PBR1倍割れ、時価総額1,000億円以下、ネットキャッシュが時価総額の50%以上（親子関係は未確認か、該当なし）
- `growth`: テンバガー候補の成長株（2016年以降に上場、役員持株15%以上、売上の3年平均成長率20%以上かつ前年比15%以上、PSR3倍以下、時価総額500億円以下、黒字）。2026-11-07 時点の EDINET DB の値で抽出

成長株は、レポートの「成長株ウォッチ」欄に**その日のすべての開示**（決算短信なども含む）を載せる。
印の意味: ✅ 好材料（上方修正、増配、自社株買い）／⚠️ 悪材料（下方修正、売出し・増資、リスク開示、無配化）／・ その他

財務の数値は EDINET DB（有価証券報告書ベース）の 2026-11-06 時点の値。
`note` 列は個別に調べた事実のメモ。「最優先」とある銘柄は、日次実行で大量保有報告を必ず確認する。

## サインと点数（TOB・非上場化の予兆としての強さ）
| サイン | 点数 |
|---|---|
| 特別委員会の設置 | 4 |
| 公開買付けに準ずる買集め行為（5%以上の買い集め） | 4 |
| 親会社・主要株主・その他の関係会社の異動 | 3 |
| 株主優待の廃止 | 3 |
| 配当の未定化・無配 | 3 |
| 中期経営計画の取り下げ・延期 | 3 |
| 上場維持基準への言及 | 3 |
| 資本業務提携 | 2 |
| 業績の下方修正 | 1 |
| 自己株式の公開買付 | 1 |
| TOB・MBO の発表と結果、完全子会社化、株式併合、上場廃止 | 0（予兆ではなくイベントそのもの） |
| 上方修正、増配、リスク開示 | 0（参考） |

予兆スコアは、ウォッチリスト銘柄の直近90日分の点数の合計。上限はない。数え方:
1. 1件の開示に複数のサインが付いたら、一番高い点数だけを採る
2. 同じ日・同じ銘柄・同じ種類のサインは1回だけ数える
3. 古いサインほど軽くする（30日で半分、60日で4分の1）

TOB・MBO・非上場化の手続きがすでに出た銘柄はスコアから外す。

## 手動で使う
```bash
python3 -I tdnet_watch.py              # 今日
python3 -I tdnet_watch.py 20261106     # 日付を指定
python3 -I tdnet_watch.py 20261006 20261106  # 期間（TDnet で見られるのは約1か月分）
```

※公表情報の機械的な分類で、投資の推奨ではありません。
